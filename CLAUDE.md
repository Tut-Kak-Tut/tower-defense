# Tower Defense

Проста tower defense гра в браузері. Запуск: відкрити `index.html` (сервер не потрібен).

## Стек
HTML5 Canvas + чистий JavaScript, без збірки і залежностей.
Скрипти — звичайні `<script>` (не ES-модулі), щоб працювало з `file://`. Порядок підключення важливий:
`config.js` → `entities.js` → `game.js` → `ui.js`. Усі мають спільну глобальну область видимості.

## Структура
- `js/config.js` — УВЕСЬ баланс: мапа/шлях, вежі, вороги, хвилі, стартові гроші/життя. Баланс правимо лише тут.
- `js/entities.js` — класи `Enemy`, `Tower`, `Projectile`.
- `js/game.js` — об'єкт стану `game`, `update(dt)`, хвилі, малювання мапи, цикл `frame`.
- `js/ui.js` — об'єкт `ui` (placing/selected/hover), події миші й клавіатури, `refreshUI()` кожен кадр, старт гри.
- `style.css` — темний інтерфейс.

## Правила
- Графіка — лише примітиви Canvas, без картинок.
- Відстані в config — у клітинках (`CELL` = 40px), швидкості ворогів — px/с.
- Нова вежа/ворог = новий запис у `TOWERS`/`ENEMIES`; спецефекти обробляються в `Projectile`.
- `refreshUI()` не перестворює DOM кожен кадр (лише textContent/класи), інакше ламаються кліки.
