# Бриф: «Серце Підземелля» на Godot для Android

## Що робимо
Порт наявної браузерної tower defense з `web/` (HTML5 Canvas + JS, ~6 тис. рядків) на Godot 4 для Android у папку `godot/`.
Макет — веб-версія: поведінка, механіки, баланс (усі числа) і вигляд мають збігатися з `web/`. Еталон — код `web/js/` і `web/CLAUDE.md`.

## Рішення замовника
- **Рушій:** Godot 4.7.2 (standard), **GDScript**. Exe: `C:\Users\Vova\AppData\Local\Microsoft\WinGet\Packages\GodotEngine.GodotEngine_Microsoft.Winget.Source_8wekyb3d8bbwe\Godot_v4.7.2-stable_win64_console.exe`. Проєкт: `godot/project.godot` (renderer Mobile, альбомна 1280×720, stretch canvas_items/expand, емуляція тачу мишею).
- **MVP:** головна з картками рівнів + кампанія (100 набігів) + усі рівні з `levels.js`; усі монстри й авантюристи; автосейв; укр/рос перемикач.
  **Не в MVP (наступний етап):** безкінечний режим, музика, колонка статистики, вікно огляду монстра 🔍 (можна спростити/пізніше).
- **Графіка:** як у вебі — примітивами через `_draw()`, без картинок і ассетів.
- **UI на телефоні:** мапа на весь екран + висувні панелі: магазин монстрів/посилення — смуга, що висувається; панель набігу — за кнопкою. Керування тачем (тап = вибрати/поселити; без hover — підказки по тапу/довгому натисканню).
- **APK:** експорт ще не налаштований → наприкінці інструкція `godot/ANDROID.md` (Android SDK, шаблони експорту, debug keystore, збірка APK).
- Розробка й тести — на ПК (headless Godot + запуск вікна).

## Обмеження
- Числа балансу — у даних (GDScript-ресурси/словники в `godot/data/`), перенесені 1:1 з `web/js/monsters/monsters.js`, `adventurers.js`, `waves/campaign.js`, `levels/levels.js`.
- Склад набігів детермінований (той самий `hash`), без `randf` у генераторах.
- Веб-версію не змінюємо.
