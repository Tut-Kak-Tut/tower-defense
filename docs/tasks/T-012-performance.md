# T-012 Продуктивність малювання + тло за межами мапи
Залежить від: T-011
Модель: sonnet
## Мета
Зараз гра на ПК дає 16–29 FPS навіть без ворогів (звіт `docs/reports/test-2026-10-03.md` п.2). Ціль — стабільні 60 FPS на ПК з 40 авантюристами і 18 монстрами, з запасом для слабкого Android.

## Файли
- змінити: `godot/scripts/draw/canvas.gd`, `godot/scripts/draw/map_fx.gd`, `godot/scripts/draw/map_layer.gd`, `godot/scripts/ui/world_view.gd`, за потреби `map_draw.gd`, `effects_draw.gd`
- створити: `godot/tests/bench.gd` (SceneTree-скрипт або сцена для виміру FPS)

## Кроки
- [ ] 1. Бенчмарк `bench.gd`: сцена гри, 18 монстрів, ~40 авантюристів (набіг 40, гроші 99999, сейв вимкнено), 600 кадрів у вікні; друкує середній FPS і середній час `_draw` кожного шару (`Time.get_ticks_usec`). Зафіксуй цифри ДО змін.
- [ ] 2. Знайди, що дорого (профілюй вимірами по шарах). Ймовірні винуватці й рішення:
  - віньєтка — повноекранний радіальний градієнт щокадру → малювати раз (окремий вузол без `queue_redraw`, перемальовувати лише при зміні розміру);
  - світло факелів — градієнти щокадру → статичне світло намалювати раз у шар без перемальовки; щокадру лише мерехтіння (дешево: напр. `modulate`/`scale` вузла або 1 простий примітив);
  - Canvas2D: кешувати тесселяцію (кола/еліпси одиничного радіуса як готові масиви, масштабувати), кеш кольорів, уникати створення масивів/об'єктів щокадру; `Canvas2D.new` щокадру — прибрати, якщо можна (переюз з reset стану);
  - тіні (`shadow_blur`) — 3 додаткових проходи на кожну фігуру → 1 прохід або вимкнути на мобільному (прапорець `Canvas2D.low_quality`);
  - градієнти в монстрах/Серці — менше кілець.
- [ ] 3. Зовнішній вигляд не повинен помітно змінитися — порівняй скріншоти до/після (`-- --demo`).
- [ ] 4. Тло за межами світу: `RenderingServer.set_default_clear_color` темний з палітри вебу (`web/style.css` `--bg` чи подібний) + цегляна рамка не обривається (або рамку прибрати, а поле лишити темним) — перевір з `--resolution 2400x1080`.
- [ ] 5. Тести `run_tests.gd` проходять.

## Готово, коли
Бенчмарк ≥ 60 FPS (vsync вимкнути при вимірі: `--disable-vsync` або `Engine.max_fps = 0`, `DisplayServer.window_set_vsync_mode`) і показує цифри до/після; скріншот не відрізняється помітно.

## Як перевірити
`"$G" --path godot res://tests/bench.tscn` (або як зробиш) — у відповіді цифри до/після.
