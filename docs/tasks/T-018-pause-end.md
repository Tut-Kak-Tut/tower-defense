# T-018 Меню паузи, кінець гри, мова
Залежить від: T-015
Модель: sonnet
## Мета
Меню паузи (☰ / «Назад») і оверлей кінця гри за `docs/gdd.md` 7.6–7.7.

## Файли
- змінити: `godot/scripts/ui/pause_menu.gd`, `godot/scripts/ui/end_overlay.gd` (заглушки з T-015 — контракт не змінювати)
- створити (за потреби): `godot/scenes/ui/pause_menu.tscn`, `godot/scenes/ui/end_overlay.tscn`

## Кроки
- [ ] 1. Пауза-меню: затемнення на весь екран + `Panel` по центру: «Продовжити», перемикач мови «UA / RU» (`I18n.set_lang` — тексти всього екрана оновлюються одразу), «Почати заново» (з підтвердженням «Точно?» → `screen.restart()`: стирає сейв цього слота і починає з нуля), «На головну» (`screen.go_home()`). Поки відкрите — `screen.set_paused(true)`, при закритті — повернути попередній стан паузи.
- [ ] 2. Кінець гри (`game.over` = "win"/"lose", показ на `screen.game_changed`): заголовок «Перемога!»/«Поразка», «Ви відбили N набігів» (тексти — з вебу `refreshOverlay`, `web/js/ui.js` 601–632), коротка статистика (вбито всього — сума `game.stats[*].kills`), кнопки «Грати знову» (`screen.restart()`) і «На головну» (≥ 64 px).
- [ ] 3. Перевірка: `-- --uitest-end`: відкрити паузу (скріншот `user://pause.png`), перемкнути мову на RU (скріншот `pause_ru.png`), поставити `game.lives = 0` → оверлей поразки (`end.png`); переглянь.

## Готово, коли
Сценарії працюють, тексти обома мовами, `run_tests` проходить.
