# T-016 Права панель: магазин монстрів і посилення
Залежить від: T-015
Модель: sonnet
## Мета
Висувна права панель за `docs/gdd.md` 7.4–7.5: вкладки «Монстри» / «Посилення».

## Файли
- змінити: `godot/scripts/ui/shop_panel.gd` (заглушка з T-015 — контракт методів не змінювати)
- створити (за потреби): `godot/scenes/ui/shop_panel.tscn`, `godot/scripts/ui/monster_card.gd`, `godot/scripts/ui/monster_info.gd`
- НЕ змінювати: `game_screen.gd` (якщо чогось бракує в контракті — опиши у відповіді)

## Кроки
- [ ] 1. Панель (`Drawer`) ~38% ширини екрана справа, виїжджає анімацією (Tween 0.2 с); вкладки вгорі.
- [ ] 2. «Монстри»: сітка 2 колонки, вертикальна прокрутка свайпом; картка — `IconView` (48 px), назва, ціна (`SoulLabel`), чіпи `UiText.monster_tags`. У рівні — лише монстри рівня (`game.map.level.monsters`), інакше `Data.monster_order`. Недоступна (`game.can_afford(type) != ""`) — приглушена, тап → `screen.toast(причина)`; доступна — `screen.select_type(type)`, картка підсвічена, поки `screen.placing_type == type`. Оновлення доступності — на `screen.game_changed`.
- [ ] 3. Довге натискання (0.4 с) на картці → вікно `monster_info` (поверх, гра на паузі, поки відкрите): опис, теги, `UiText.stat_rows(def, [1, 5, 10])` таблицею, кнопка «Закрити».
- [ ] 4. «Посилення» (коли `screen.selected`): іконка, назва, рівень N/10, таблиця «зараз → після» (`UiText.upgrade_info`), кнопка «Посилити (ціна)» (≥ 56 px; неактивна, якщо мало душ або рівень 10) → `game.upgrade_tower`; «Продати (сума)» → перший тап змінює текст на «Точно?» на 2 с, другий — `game.sell_tower` + `screen.clear_selection()`.
- [ ] 5. Режим цілі: рядок чіпів з `Tower.TARGET_MODES` лише якщо `t.aims()`; активний підсвічений; тап → `t.aim = mode`.
- [ ] 6. Біхолдер (`def.fixedDir`): кнопки напрямку за `Rules.DIRS` → `t.set_dir(i)`; превʼю смуги вже малює WorldView для вибраного.
- [ ] 7. Орк (`attack == "manual"`): кнопка «Кинути валун (N)» → `game.throw_boulder(t)` (як у вебі: подвійний клік = кидок одразу, без вибору точки — тож просто кнопка).
- [ ] 8. Після будь-якої дії — автосейв, як у вебі (перевір, що GameState сам викликає `_autosave` у place/upgrade/sell; якщо ні — опиши).
- [ ] 9. Мова: на `I18n.lang_changed` перебудувати тексти.
- [ ] 10. Перевірка: аргумент `-- --uitest-shop` (свій сценарій у shop_panel або окремий dev-скрипт): відкрити панель, скріншот обох вкладок (`user://shop_1.png`, `shop_2.png`), посилити, продати; переглянь PNG.
